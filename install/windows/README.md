cmSessions-Setup.exe is the one-click per-user installer for people putting cmSessions on their own 64-bit Windows PC.
It installs sessions_page.exe standalone and offers the cmCode AI harness dependency, checked by default. That step runs install_cmcode_dep.ps1 so AI harness access is available. sessions_page.exe and cmCode stay separate binaries. Setup does not start sessions_page.exe.
Running sessions_page.exe still needs no Python. Python and Git are only for the cmCode dependency. If cmcode, cosmos-code, or a copy under %LOCALAPPDATA%\Programs\cmCode (or Programs\COSMOS\cmCode) is already present, the script says so and exits. Otherwise it copies V:\a\ai\cmCode when that tree is on the machine, or it clones https://github.com/keithbbf-gif/cmCode.git and runs pip install --user into %LOCALAPPDATA%\Programs\cmCode, then adds that folder and cmcode.cmd to the per-user PATH. If the PC is offline or has no Python and no Git, the script prints `pip install git+https://github.com/keithbbf-gif/cmCode.git` and leaves the cmSessions files in place.
Silent test: cmSessions-Setup.exe /VERYSILENT /NORESTART /DIR=<folder>
